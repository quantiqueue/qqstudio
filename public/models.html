Server

    
By default qqstudio only answers on this computer. Turn on network access to use it from your phone, tablet or another PC on the same network.

    

      
      

      
You're connected from another device. These settings can only be changed on the computer running qqstudio.

      

        
Open on another device

        

        
Each device needs the link once (it contains the access key). After that the plain address works in that browser.

        
Access key

        
••••••••A new key signs out every other device.

        
Anyone with the link can chat and run the tools you allow here, including file and download tools. Only use this on a network you trust. The first time, Windows may ask to let Node.js through the firewall: allow it on Private networks.

Session Compaction

    

      
%

      
Sessions will compact when the context window reaches this maximum. The older part is summarized by the model and replaced by the summary in what it is sent; the full history stays in the session. Leave blank to turn it off.

MCP Servers

    
Model Context Protocol servers add tools from other programs. Same format as Claude Desktop's claude_desktop_config.json. Their tools appear in Tools (Ask first is on by default) and can be switched per chat from the + menu.
